项目核心目标

在微信生态内，打造又快、又省心、又划算的话费充值体验，建立以智能化(Agent)为核心的可持续增长与变现能力。

核心原则：以用户体验为中心，通过AI Agent降低操作成本，提升充值转化率与用户留存

前置调研核心痛点

  • 操作路径冗长：充值平均点击≥5次，金额选择页转化率流失率达65%（核心原因：优惠/到账时效不清晰）
  • 用户分层痛点：
    • 新用户：关注号码自动识别、失败退款、到账时效
    • 老用户：关注一键复购、自动充值、多号码管理
  • 消息触达混乱：服务通知、模板消息、短信并行推送，用户投诉率月均增长12%

4. AI Agent 设计(充值智能体)

4.1 定位："你的一站式充值管家"

  • 第一阶段（1-8周）：对话式Chatbot，支持基础Agent操作（充值/查询/推荐）
  • 第二阶段（9-12周）：适配微信大一统Agent，实现全流程自动化
  • 核心价值：主动读懂用户习惯与偏好，提供"更快、更划算、更智能、更省心"的充值服务

4.2 核心能力

全自动操作 感知与预测 对话理解 个性化推荐 多模态交互 安全风控
全自动操作
授权后自动完成订单创建-支付-结果反馈，支持无感支付和一键撤销
感知与预测
基于历史数据预测充值时间与金额，余额低于阈值时提前12小时提醒
对话理解
解析复杂自然语言指令，支持语音/快捷指令/图片号码识别
安全风控
敏感操作二次验证，单日代扣金额上限500元，异常订单自动兜底退款

4.3 交互形态

4.3.1 原"手机充值"入口优化

入口触发逻辑：点击"手机充值"后，右下角弹出客服气泡"您好，我是小微，请问您是否需要我帮您进行手机充值？"，配"是"（绿色）、"暂不需要"（灰色）按钮，无关闭控件

主界面：关闭弹窗后保留原有功能（号码/金额选择/充流量等），新增"唤醒小微"按钮（带客服标识），点击弹出聊天窗口，支持文字/语音实时互动

4.3.2 Agent专属入口

  1. 主动触发式服务（用户驱动）：

    文字/语音指令直接触发，核心支持场景：

    • 精准充值："给139XXXXXXXX充100元"
    • 套餐查询："本月套餐还剩多少流量/话费"
    • 业务办理："办理20元流量加油包"
    • 通用问答："话费充值后怎么开发票"
  2. 选项引导式服务（元宝驱动）：

    打开对话框或发送模糊指令后，弹出快捷菜单：

    根据"充值话费"，为您推荐以下服务：
    1. 一键充值（按默认设置充值/同额再充）
    2. 套餐优化推荐（基于您的消费习惯）
    3. 流量包选购（精准匹配您的使用需求）
    4. 余额/用量查询
    5. 管理我的设置
    6. 更多服务
  3. 自动化服务：
    • A. 半自动（一键按钮）：聊天底部常驻"一键充值（主号/家庭组合）""常用号码一键充值"快捷按钮
    • B. 全自动（免密托管）：用户设置触发条件（如余额低于20元），系统实时监控并自动充值，仅推送结果通知
  4. 智能推送式服务：每月1日推送月度账单报告、套餐优化建议、专属优惠（如"充100送5元"）
  5. 预警通知服务：余额低于阈值时弹窗提醒"⚠️ 你的话费余额已不足10元，点击【立即充值】或检查自动充值设置"

4.4 技术与风控

4.4.1 套餐推荐模型

  • 核心数据维度：号码属性、归属地、历史充值面额、充值频率、渠道偏好、Agent功能接受度
  • 核心技术栈：轻量预测模型（消费周期/方案排序）、风控规则模型、运营商API实时对接、数据分钟级更新
  • 知识储备：充值规则库、支付失败处理流程、PCI DSS支付安全标准、运营商套餐知识库

4.4.2 安全与合规预案（新增细则）

  • 数据安全：遵循"存储最小化+匿名化"原则，仅存储必要的充值相关数据，明示授权范围与使用期限
  • 权限管控：敏感操作（代扣/代充）需二次确认+短信验证，单日代扣金额上限500元
  • 宣传合规：禁止使用"100%到账""包满意"等夸大话术，内置敏感词过滤系统
  • 异常处理：到账延迟＞10分钟自动触发申诉流程，失败订单自动兜底退款（最长1小时）
  • 边界管控：非充值相关业务（如金融、广告）拒绝回答，设置知识栅栏防止提示词注入
  • 隐私保护：用户可随时查看/删除/导出个人数据，支持一键注销Agent服务
5. 运营策略(拉新/促活/转化/留存/变现)

5.1 渠道与分发

  • 站内核心渠道：
    • 朋友圈精准投放Agent体验广告（定向高价值用户）
    • 旧充值入口增加"体验智能充值"引导按钮（占比30%视觉空间）
    • Agent对话框主动唤起用户感知（首次使用送2元充值券）
    • 服务通知嵌入智能充值入口（账单日/余额低时）
  • 站外辅助渠道：小红书/抖音/快手发布"智能充值"体验短视频，重点突出"10秒充值"核心卖点

5.2 重点运营活动

活动规则：所有优惠券有效期7天，自动充值返现金额可累积，最高返现比例5%；会员日为每月15日，充值额外赠送10%积分（可兑换话费）

5.3 增长与留存机制

  • 任务制成长体系：首充→复购→开通自动充值→多号管理→开通家庭会员（逐步解锁更高优惠）
  • 成就与权益：根据活跃等级解锁手续费优惠（最高免1元/笔）、专属优惠券、优先人工客服
  • 召回策略：
    • 30天流失用户：赠送1元无门槛充值券+对话式召回脚本
    • 50天流失用户：赠送2元无门槛券+自动充值体验卡（7天）
    • 90天流失用户：赠送5元满减券+家庭充值礼包
  • 口碑传播：邀请好友使用智能充值，双方各得3元充值券（好友完成首充后生效）
